Accessibility Statement

We aim to make this platform usable for users of all abilities by implementing features such as:

  • Keyboard navigation for core functionality
  • High-contrast colour schemes and clear icons
  • Responsive layouts for mobile and desktop devices
  • Text compatible with screen readers
  • Category filters to find a chosen product
  • A product search bar to help users find products more quickly.

Known limitations:

  • Some screen reader interactions may be inconsistent
