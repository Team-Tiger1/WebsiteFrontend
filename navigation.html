Keyboard Navigation Instructions

This website is fully keyboard navigation accessible

Use tab to move forward through the elements and use shift+tab to navigate backwards.

Press enter to activate a selected link or button. On a drop down menu use arrows to move between options.

The element that you are focused on will be highlighted so you can always see where you are on the page.

The page is also fully screen reader accessible with labels to provide context to all areas of the page.
